📱 내 핸드폰에 앱으로 설치하기

아이폰 (iPhone / iPad - Safari)

  1. 화면 하단 중앙의 공유 아이콘() 클릭
  2. 메뉴를 내려 '홈 화면에 추가' 선택
  3. 우측 상단 '추가' 클릭하면 바탕화면에 앱 아이콘 생성

안드로이드 (Galaxy - 크롬/삼성인터넷)

  1. 우측 상단 메뉴(⋮) 클릭
  2. '앱 설치' 또는 '홈 화면에 추가' 선택
  3. 팝업창에서 '설치' 클릭 시 단독 앱으로 등록
